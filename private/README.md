# Приватная часть (после регистрации)

Сюда попадают файлы, которые **не** публикуются открыто и выдаются устройству
после оплаты и регистрации:

```
private/
  users/<email-hash>/profile.json   профиль клиента (hysteria2/vless), выданный пользователю
  users/<email-hash>/server.txt     адрес и порт его выделенного IP
  templates/                        шаблоны профилей для выдачи
```

Доставка на устройство:

1. **через git** — клонирование приватного репозитория с токеном:
   `git clone https://<token>@github.com/<owner>/netmon-private.git`
2. **с сервера** — `scp`/`ssh` с ключом устройства; адрес и ключ выдаются службой
   регистрации вместе с конфигурацией.

Правила:
- токены и профили не попадают в публичный репозиторий (проверяется `.gitignore`);
- у каждого пользователя свой каталог, ключ каталога — sha256(email)[:16];
- при удалении пользователя каталог архивируется, IP возвращается в пул.
