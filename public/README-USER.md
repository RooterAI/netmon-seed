# Как подключить гарнитуру к интернету через ПК

1. Запустите установщик `Install-Netmon.ps1` от администратора.
2. Дождитесь значка в трее — очки означают, что монитор работает.
3. На ПК включится раздача Wi-Fi (кнопка «Хотспот» или автоматически).
4. На гарнитуре (Meta Quest 3 / Quest S / Quest Pro или другой VR-шлем)
   откройте **Настройки → Wi-Fi** и подключитесь к сети ПК.
5. Проверьте интернет в браузере гарнитуры.

Если интернета нет:

* откройте окно netmon и нажмите **«Восстановить сеть»**;
* посмотрите блок «Рекомендации» — там написано, что именно случилось;
* кнопка **«Справка»** открывает встроенную базу знаний.

Данные для подключения другого устройства (телефон, второй шлем) выдаёт кнопка
**«Подключение»** — появится QR-код, его достаточно отсканировать.
