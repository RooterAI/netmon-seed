# Netmon Seed — публичный пакет для VR-устройств

Публичный репозиторий с **сид-пакетом**: установщик и клиент мониторинга сети,
который поднимает VPN и раздачу интернета на ПК, к которому подключена гарнитура.

Совместимость с устройствами VR: **Meta Quest 3, Quest S (Quest 2/3S), Quest Pro**
и другие гарнитуры, работающие по Wi-Fi через точку доступа ПК. Устройство
подключается к сети хотспота и получает интернет через туннель ПК — отдельный
клиент внутри гарнитуры не нужен.

> Репозиторий не является продуктом Meta Platforms, Inc. и не связан с ней;
> Meta, Quest — товарные знаки соответствующих правообладателей. Здесь описан
> только способ подключения гарнитур к сети ПК.

## Что лежит в публичной части

| Файл | Назначение |
|---|---|
| `Install-Netmon.ps1` | установщик: скачивает пакет, проверяет SHA-256, ставит задачу автозапуска |
| `manifest.json` | версия, ссылка на файл, контрольная сумма |
| `netmon.exe` | клиент (сид): мониторинг, VPN, хотспот, диагностика |
| `README-USER.md` | короткая инструкция для конечного пользователя |

## Что выдаётся после регистрации (приватная часть)

Профили подключения, персональные конфигурации и ключи в публичный пакет
**не входят**. После оплаты и регистрации устройство забирает их из приватного
репозитория (доступ по токену) или с самого сервера по SSH/git.

## Быстрый старт

```powershell
# 1. скачать установщик
irm https://raw.githubusercontent.com/<owner>/netmon-seed/main/public/Install-Netmon.ps1 -OutFile Install-Netmon.ps1

# 2. установить (нужен запуск от администратора)
powershell -ExecutionPolicy Bypass -File .\Install-Netmon.ps1
```

Установщик кладёт клиент в `C:\Program Files\netmon`, создаёт задачу
планировщика `netmon` (запуск при входе, наивысшие права) и запускает клиент.

## Что нового в 2.9.0

* Сторож транспорта: `transport on` теперь запоминает желаемое состояние, и монитор
  сам возвращает свой путь после падения ядра (~1 с), вмешательства в системный прокси

  настоящей поломке — прокси смотрит на остановленное ядро.
* Справка: статьи «Свой транспорт: ядро, релей, прокси» и «Своё ядро: как оно работает».

## Что нового в 2.7.0

## Обновления

Клиент сам проверяет `manifest.json` (режим `update_mode` в `netmon.ini`):

```powershell
netmon.exe --cli update check     # есть ли новая версия
netmon.exe --cli update apply     # скачать, проверить SHA-256, подменить и перезапуститься
netmon.exe --cli self             # версия, права, автозапуск, журнал
```

Версия задана в одном месте исходников (`src\version.h`), поэтому манифест и клиент
всегда согласованы: `publish.ps1` берёт номер из `netmon.exe --cli self`.

## Сборка и публикация

```powershell
powershell -ExecutionPolicy Bypass -File .\publish.ps1 -Version 2.5.2 -Push
```

`publish.ps1` копирует свежий `netmon.exe` в `public/`, считает SHA-256,
переписывает `manifest.json` и делает коммит; с `-Push` отправляет в GitHub.
